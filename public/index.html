Designing a Portfolio as a Human Factors Problem

A portfolio is itself an interface. I'm exploring what happens when the process of designing one is treated as a Human Factors problem rather than simply a visual design exercise.

Current Project

The portfolio is part of the research.

The goal is not simply to create a portfolio that looks good. I want to understand whether its information architecture helps visitors find the information they actually need.

Current phase
Architecture + usability planning
Focus
Information architecture, usability, recruiter behavior
Methods
Task analysis, usability testing, behavioral measures

01

The Problem

A portfolio has very little time to make itself understandable.

Recruiters may have only a limited amount of time to determine whether a candidate is relevant. A portfolio therefore needs to provide enough information to support that decision without overwhelming the person trying to use it.

02

The Question

Can a portfolio built around progressive disclosure help visitors locate important candidate information quickly and confidently?

03

The Approach

Design it. Observe it. Revise it.

01

Define likely recruiter information needs

02

Design the information architecture

03

Build and iterate the portfolio

04

Test representative tasks

05

Measure performance and revise

04

Current Design Response

Reduce choices first. Reveal depth when it becomes useful.

The current design limits the opening experience to a small number of high-value choices while preserving scrolling as another path through the portfolio.

Focused hero Progressive disclosure Clear project access Persistent résumé access Recent work through scrolling

05

Testing the Design

The next step is to see how people actually use it.

Representative visitors can be asked to locate information such as education, research methods, project experience, résumé access, and contact information.

Task completion Time on task Navigation path Errors Confidence

Work in Progress

This project will evolve as testing produces new evidence and new iterations.
